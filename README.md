# 🎮 k399game

**Every Game, 100% AI Generated.**

A curated platform for games created entirely by artificial intelligence — from code to mechanics, all born from prompts. No human game coding involved.

---

## ✨ Features

- **100% AI-Crafted Games** — Every pixel, every line of code generated by AI
- **Instant Browser Play** — No downloads, no installs. Just click and play
- **Curated Collection** — Hand-picked best AI game creations
- **i18n Support** — English & Chinese bilingual interface
- **Dark Theme** — Neon green accent on dark background

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **i18n**: next-intl (EN / ZH)
- **Deployment**: Cloudflare Pages + R2

## 🚀 Getting Started

```bash
# Install dependencies
npm install --legacy-peer-deps

# Start development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to see the platform.

## 📁 Project Structure

```
src/
├── app/
│   ├── layout.tsx              # Root layout (HTML/body + CSS)
│   ├── page.tsx                # Language redirect
│   ├── globals.css             # Global styles + Tailwind
│   └── [locale]/
│       ├── layout.tsx          # Locale layout (Header + Footer)
│       ├── page.tsx            # Homepage
│       └── games/[slug]/page.tsx  # Game detail (iframe)
├── components/
│   ├── Header.tsx              # Navigation + language switch
│   ├── HeroSection.tsx         # Hero with animated background
│   ├── FeaturesSection.tsx     # 3 feature cards
│   ├── GameCard.tsx            # Game thumbnail card
│   ├── GameGrid.tsx            # Category filter + grid
│   ├── SubmitSection.tsx       # Game submission CTA
│   └── Footer.tsx              # Site footer
├── data/games.ts               # Game data + categories
├── i18n/
│   ├── request.ts              # next-intl config
│   └── messages/{en,zh}.json  # Translations
└── middleware.ts               # Locale detection
```
